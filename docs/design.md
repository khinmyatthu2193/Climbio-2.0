# Climbio Design System

## Product Identity

Climbio is a modern SaaS platform for small business owners to manage:

- Products
- Inventory
- Sales
- Invoices
- Public product catalogs
- Business insights


## Design Philosophy

Climbio should feel:

- Professional
- Trustworthy
- Simple
- Modern
- Efficient
- Business-focused


The UI should help small business owners complete tasks quickly.

Avoid:

- Complex enterprise feeling
- Overly decorative design
- Unnecessary animations
- Confusing layouts


---

# Brand Personality

Keywords:

- Growth
- Organization
- Reliability
- Simplicity
- Success


Visual feeling:

"Professional business assistant for every shop owner."


---

# Design Principles


## 1. Clarity First

Every screen should answer:

"What can the user do here?"


Prioritize:

- Clear actions
- Simple navigation
- Visible information hierarchy


---

## 2. Consistency

All pages must share:

- Same spacing
- Same colors
- Same typography
- Same component style


Do not create one-off designs.


---

## 3. Mobile First

Many shop owners use phones.

Every page must support:

- Mobile screens
- Tablet
- Desktop


Important:

- Buttons must be touch-friendly
- Tables need mobile alternatives
- Forms must be easy to complete


---
# Climbio Visual Design System

## Brand Direction

Climbio is a modern SaaS platform for small business owners.

The design should communicate:

- Trust
- Growth
- Simplicity
- Professionalism
- Modern technology


The overall feeling:

"An elegant business assistant that helps shop owners grow."


---

# Visual Style

Design inspiration:

- Modern SaaS applications
- Premium mobile applications
- Clean business dashboards

Visual characteristics:

- Soft rounded corners
- Clean layouts
- Comfortable spacing
- Minimal but elegant
- Subtle gradients
- Soft shadows
- Clear typography


Avoid:

- Overly complex enterprise UI
- Heavy decorations
- Excessive animations
- Crowded layouts

# Gradient Usage


Gradients can be used for:

- Auth pages
- Hero sections
- Empty states
- Premium highlights


Recommended:

Purple gradient:

#8B5CF6 → #C084FC


Soft background gradient:

#F5F3FF → #FFFFFF


Do not use gradients everywhere.


---

# Card Style


Cards should have:


Border radius:

16px - 24px


Shadow:

Soft and subtle


Example feeling:

Modern mobile app cards.


Cards should not look heavy.


---

# Button Style


Primary button:

Purpose:

Main action.


Examples:

- Login
- Create account
- Add product
- Save


Style:

- Rounded
- Purple background
- White text
- Smooth hover


Secondary button:

- Transparent or light background
- Purple border/text


Danger button:

- Red theme


---

# Input Design


Inputs should have:

- Rounded corners
- Clear labels
- Comfortable height
- Soft borders
- Visible focus state


Focus:

Purple outline/glow.


Error:

Red border + helpful message.


---

# Authentication Pages Design


Login and Register pages should feel:

- Welcoming
- Premium
- Simple


Layout:

- Centered card
- Soft background
- Minimal decoration
- Clear CTA


Components:

- Logo
- Welcome message
- Form
- Password visibility toggle
- Theme switcher
- Navigation between login/register


---

# Auth Page Illustration Style


Optional visual elements:

- Soft abstract shapes
- Purple gradients
- Minimal illustrations


Avoid:

- Busy images
- Distracting graphics


---

# Icons


Use:

- Clean outline icons
- Consistent stroke width


Examples:

- Eye icon for password visibility
- Settings icon
- Search icon
- Notification icon


---

# Responsive Rules


Mobile first approach.


Mobile:

- Full width cards
- Large touch targets
- Simple navigation


Desktop:

- Centered layouts
- More whitespace
- Dashboard sidebar


---

# Animation Rules


Use subtle animations:

Allowed:

- Fade in
- Hover transition
- Button interaction
- Modal animation


Avoid:

- Excessive motion
- Distracting effects


---

# UI Implementation Rules


Before creating new UI:

1. Check existing components.
2. Reuse components.
3. Follow theme tokens.
4. Maintain consistency.


Never create random colors.

Always use design system colors.
