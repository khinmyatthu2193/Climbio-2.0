Climbio User Manual

သုံးစွဲသူလမ်းညွှန်

Climbio ကို စတင်အသုံးပြုခြင်းမှ အရောင်း၊ ကုန်ပစ္စည်း၊ Public Store နှင့် AI အကြံပေးအထိ ရှင်းလင်းလွယ်ကူသော မြန်မာဘာသာ အဆင့်လိုက်လမ်းညွှန်။

လမ်းညွှန်အခန်း၆ ခန်း
ပုံနှင့် ရှင်းလင်းချက်၁၇ ခု
သင့်ပြီးစီးမှု၀%
အကြောင်းအရာများ
၀ / ၆ ခန်း ပြီးစီး

Climbio ကို လေ့လာပါ

အခန်းခေါင်းစဉ်ကို နှိပ်၍ ဖွင့်/ပိတ်နိုင်ပါသည်။

၆ ခန်းလုံး
ကိုက်ညီသောအကြောင်းအရာ မတွေ့ပါ

အခြားစကားလုံးဖြင့် ထပ်မံရှာဖွေပါ။

👤 အကောင့်အသစ်ဖွင့်ခြင်း

Register စာမျက်နှာမှ ဆိုင်ပိုင်ရှင်အကောင့်ကို ဖန်တီးပါ။

၁

Register ကိုနှိပ်ပြီး အမည်၊ ဆိုင်အမည်နှင့် Email ဖြည့်ပါ။

၂

ခန့်မှန်းရခက်သော Password ထည့်ပြီး အချက်အလက်ကို ပြန်စစ်ပါ။

၃

Create account ကိုနှိပ်ပြီး Email Verification ရရှိပါက အတည်ပြုပါ။

📝[Screenshot: Registration Form]အကောင့်ဖွင့်ရန် ဖောင်
✉️[Screenshot: Email Verification]Email အတည်ပြုခြင်း
💡 အကြံပြုချက် — သင်ပုံမှန်အသုံးပြုသော Email ကိုသာ ထည့်ပါ။ Verification မရပါက Spam folder ကို စစ်ပါ။

🔐 Login ဝင်ခြင်း

၁

မှတ်ပုံတင်ထားသော Email နှင့် Password ကို ထည့်ပါ။

၂

Sign in ကိုနှိပ်ပါ။ အများသုံးစက်တွင် ပြီးပါက Log out လုပ်ပါ။

🔑[Screenshot: Login Page]အကောင့်ဝင်ရန် စာမျက်နှာ

🏪 ဆိုင်လျှောက်လွှာ

၁

ဆိုင်အမည်၊ လုပ်ငန်းအမျိုးအစား၊ ဖုန်းနှင့် လိပ်စာကို ပြည့်စုံစွာ ဖြည့်ပါ။

၂

လျှောက်လွှာတင်ပြီး Pending အခြေအနေတွင် စောင့်ပါ။

၃

Approved ဖြစ်လျှင် Workspace ကို အပြည့်အဝ အသုံးပြုနိုင်ပါပြီ။

📋[Screenshot: Application Form]ဆိုင်လျှောက်လွှာဖောင်
✅[Screenshot: Application Status]လျှောက်လွှာအခြေအနေ

📊 Dashboard အနှစ်ချုပ်

ဆိုင်၏အခြေအနေကို တစ်နေရာတည်းတွင် ကြည့်နိုင်သည်။

📈[Screenshot: Dashboard Overview]လုပ်ငန်းအခြေအနေ အနှစ်ချုပ်

🎯 အဓိက Metrics

၁

Revenue သည် Paid Invoice များမှ ရရှိသော ဝင်ငွေဖြစ်သည်။

၂

Stock on Hand သည် လက်ရှိရောင်းချနိုင်သော စုစုပေါင်းစတော့ဖြစ်သည်။

၃

Low Stock သည် သတ်မှတ်အရေအတွက်အောက် ရောက်နေသောပစ္စည်းများဖြစ်သည်။

💡 ဘယ်ဘက် Sidebar မှ Products, Invoices, AI Advisor, Public Store နှင့် Settings သို့ သွားနိုင်ပါသည်။

📦 Product List

Search နှင့် Filter များသုံး၍ ပစ္စည်းရှာပါ။ Edit မှ ဈေးနှုန်း၊ ပုံနှင့် စတော့ကို ပြင်ပါ။

📦[Screenshot: Product List]ကုန်ပစ္စည်းစာရင်း

➕ ပစ္စည်းအသစ်ထည့်ခြင်း

၁

Add Product ကိုနှိပ်ပါ။

၂

အမည်၊ ဈေးနှုန်း၊ Stock, Category နှင့် ဖော်ပြချက်ကို ဖြည့်ပါ။

၃

ရှင်းလင်းသောပုံထည့်ပြီး Public Store တွင် ပြလိုပါက Visibility ဖွင့်ကာ Save လုပ်ပါ။

🖼️[Screenshot: Add Product Form]ပစ္စည်းအသစ်ဖောင်
🏷️[Screenshot: Category Management]အမျိုးအစားစီမံခြင်း
⚠️ ပစ္စည်းဖျက်မည်ဆိုပါက Invoice အဟောင်းများနှင့် ဆက်စပ်မှုရှိ/မရှိ အရင်စစ်ပါ။

🧾 Invoice စီမံခြင်း

၁

Invoice List တွင် အရောင်းမှတ်တမ်းနှင့် Status ကို စစ်ပါ။

၂

Create Invoice တွင် ဝယ်ယူသူနှင့် ပစ္စည်းများထည့်ပြီး Total ကို စစ်ပါ။

၃

သိမ်းပြီး Invoice Detail မှ PDF ကို Preview ကြည့်ကာ Download လုပ်ပါ။

📑[Screenshot: Invoice List]ဘောက်ချာစာရင်း
✍️[Screenshot: Create Invoice]ဘောက်ချာဖန်တီးခြင်း
📄[Screenshot: PDF Preview]PDF အစမ်းကြည့်ခြင်း
⚠️ ငွေလက်ခံရရှိကြောင်း အတည်ပြုပြီးမှ Invoice ကို Paid အဖြစ် ပြောင်းပါ။

🌐 အများမြင်ဆိုင် မျှဝေခြင်း

၁

ပစ္စည်းများကို Active/Public ဖြစ်အောင်ထားပြီး Public Page Settings ကို စစ်ပါ။

၂

Public Page View ကို Preview ကြည့်ပြီး ဆိုင်အချက်အလက်နှင့် ပစ္စည်းမှန်ကြောင်း စစ်ပါ။

၃

Link ကို Copy သို့မဟုတ် QR Code ကို Download လုပ်၍ မျှဝေပါ။

⚙️[Screenshot: Public Page Settings]Public Page ဆက်တင်
▦[Screenshot: QR Code]ဆိုင် QR Code
🏬[Screenshot: Public Page View]ဖောက်သည်မြင်ရသည့် ဆိုင်စာမျက်နှာ
💡 Link မမျှဝေမီ Browser Incognito Mode ဖြင့် ဖောက်သည်မြင်ရမည့်ပုံစံကို စမ်းပါ။

📈 အရောင်းအစီရင်ခံစာ

Dashboard မှ ၇ ရက်၊ ၃၀ ရက် သို့မဟုတ် ၆ လ ကာလကို ရွေးပြီး Revenue နှင့် ရောင်းအားအပြောင်းအလဲကို ကြည့်ပါ။

📊[Screenshot: Sales Chart]ကာလအလိုက် အရောင်းဇယား

🤖 AI Business Advisor

၁

Analyze My Business ကိုနှိပ်၍ ဆိုင်မှတ်တမ်းများကို သုံးသပ်ပါ။

၂

အကြံပြုချက်၊ စတော့သတိပေးချက်နှင့် ရောင်းအားအချက်အလက်များကို ဖတ်ပါ။

၃

Chat တွင် “ဘယ်ပစ္စည်း ပြန်ဖြည့်သင့်လဲ” ကဲ့သို့ တိကျသောမေးခွန်း မေးပါ။

✨[Screenshot: AI Advisor]AI သုံးသပ်ချက်နှင့် အကြံပြုချက်
